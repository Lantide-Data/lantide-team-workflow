# Workflow: new formal analysis

## Use when

Use this workflow for a new decision question, metric, denominator, source boundary, analytical contract, or durable deliverable. Do not use it merely because an existing artifact has not yet been inspected.

## Procedure

1. Confirm the decision, requester, audience, expected output, and why the result matters.
2. Identify the intended data sources and material unknowns. Resolve ambiguity that would change scope or metric meaning.
3. Establish the correct workspace and project. Reuse an existing project for the same durable question when appropriate.
4. Load the live Plan-authoring methodology and create a Plan containing the agreed scope, definitions, assumptions, validation checks, and Report contract.
5. Hand the Plan to the reviewer required by team policy and the current Lantide access mode. Do not treat chat prose as a substitute for the authoritative Plan.
6. After approval, use the current execution reference and live execution methodology for every formal step. Keep exploration separate from formal evidence.
7. Validate grain, joins, denominators, missingness, reconciliation, and other checks material to the claims.
8. Produce the required Report from formal evidence, apply the live verifier, and disclose limitations.
9. Read back the final artifact and verify its evidence chain before announcing completion or distribution.

## Stop or replan when

Stop and seek a decision when the source is unavailable, a definition is unresolved, evidence contradicts the Plan, a material assumption changes, or the requested result would exceed approved access. Follow the live deprecation or replanning workflow rather than silently rewriting an executing contract.

## Completion criteria

- The decision question and audience are explicit.
- A reviewed Plan represents the executed contract.
- Every material claim is supported by formal evidence.
- Required checks are recorded, not merely asserted in chat.
- The Report answers the question and states limitations.
- The final artifact and lifecycle state were read back and verified.
